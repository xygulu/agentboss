# BossHost 工头主机（口袋工头）安装与使用说明

把电脑上的 Claude Code 投到手机上用：手机浏览器里看实时画面、发消息、遥控终端里的 claude 会话。全彩渲染，与电脑端显示一致。

## 环境要求

- macOS（Apple Silicon / Intel 均可）、Windows 10/11、或 Linux（见下方「Linux 开发机」一节）
- 装好 [Claude Code](https://docs.claude.com/en/docs/claude-code)（终端里能敲 `claude` 即可）
- 用 [Codex CLI](https://github.com/openai/codex) 的也一样：终端里敲 `codex` 跑起来的会话会自动出现在列表里，
  看回话、发消息、召回、复制、删除都跟 Claude 会话一样用（跑完提醒需要 BossHost 装一次 notify，
  装客户端时自动完成；你自己的 `notify` 会保留，上报完照旧转给你）
- 手机和电脑同一个 Wi-Fi 最省事；不在同一网络也能用——配对后自动走中继/打洞直连

Python 不用管：每个平台的安装包都自带一份 Python 3.11，装完不受这台机器上有没有 Python 影响，
也不用联网另外装解释器。（Linux 的 arm64 包暂未内置，安装脚本会自动下载一个匹配的版本。）

## macOS 安装（约 1 分钟）

1. 双击 `BossHost-*.dmg`，把里面的 `BossHost.app` **拖进「应用程序」文件夹**
   - **一定放「应用程序」**：App 以后靠自动更新原地替换自己。留在 DMG 里或下载目录里直接运行，
     更新时没法原地替换，每次都要重新下载、重新授权；如果 App 还留在 DMG 里，
     推出 DMG 或重启电脑后它就"没了"。
   - 忘了拖也没关系：从下载目录直接双击 App 时，它会弹「把 BossHost 移到「应用程序」」，
     点这个按钮即可（自动复制过去并重启，以后更新全自动）。
2. 第一次打开会被 macOS 拦一下——App 没有做苹果公证，**这是正常的，只需授权一次**：
   - **macOS 15 及更新版本（含 macOS 26）**
     1. 双击 `BossHost.app`，弹出「"BossHost" 无法打开，因为 Apple 无法验证此 App 是否包含恶意软件」
        → 点「**完成**」（**千万别点「移到废纸篓」**）
     2. 打开 系统设置 → **隐私与安全性**，滚到页面最下面的「**安全性**」区域
     3. 看到「已阻止使用"BossHost"，因为来自身份不明的开发者」→ 点「**仍要打开**」
     4. 输入 Mac 的开机密码（或 Touch ID），弹窗里再点一次「**打开**」
   - **macOS 14 及更早**：右键（或按住 Control 点）`BossHost.app` →「**打开**」→ 弹窗里再点「**打开**」
   - 授权成功后以后双击就不会再弹了。若双击后"什么也没发生"，
     看屏幕**右上角菜单栏**有没有出现 BossHost 图标——它是菜单栏程序，不开主窗口。
3. 点菜单栏的 BossHost 图标 →「安装 BossHost 服务」（只影响本机后台，退出 App 也照常跑），
   装完再点「扫这个码接上」，屏幕上出现二维码（15 分钟内有效）
4. 手机扫二维码（或手动输入网址），即可使用

> 首次安装服务时可能还会弹「"BossHost" 想要控制"终端"」这类系统授权，点「好 / 允许」。
> 也提供 tar.gz（终端安装）：解压后双击 `安装.command`，同样会被拦一次，
> 到 系统设置 → 隐私与安全性 →「仍要打开」即可。服务装在 `~/.codeboss`，
> 装完安装包随便推出/删除，不影响使用。
> 安装是幂等的：重复安装/更新 = 升级到新版本，token 和历史记录都会保留。

## Linux 开发机

一条命令装完，终端里出二维码，手机 App 扫码绑定：

```bash
tar xzf codeboss-*.tar.gz && cd codeboss-*/
bash install-linux.sh
```

脚本会自动：建虚拟环境装依赖 → 注册 systemd 用户服务（开机自启，SSH 断开也不停）→
往 `~/.bashrc` / `~/.zshrc` 写 `claude` 别名 → 自动登记中继 → 打印绑定二维码。

- **绑定**：手机打开工头 App（口袋工头 / 代理工头） →「接入开发机」→「📷 扫码接入」（列表页点「绑定开发机」卡片、
  或右上「＋」也是同一页），对着终端里的二维码扫一下。二维码 15 分钟有效，过期在终端输入
  `codeboss` → 选「扫这个码接上…」换一张
- **命令行客户端**：装好后终端直接输入 `codeboss` 就是菜单（和 macOS 菜单栏 App 同一套功能）：
  配对二维码、会话列表、启动/停止服务、重新安装、检查更新、套餐与续费、日志、卸载。
  每条菜单都对应一条子命令，SSH 里也能用：`bosshost status|qr|sessions|start|stop|restart|
  reinstall|uninstall [--purge]|account|logs [-f]|update`
- **前置**：`tmux`（`sudo apt install -y tmux`，手机端「打开终端」要用）、能敲 `claude`。
  Python 不用装：x86_64 包自带；arm64 机器上脚本会自动下载一个匹配的版本（一次性，需联网）
- **重复运行 = 升级**：token、会话记录、虚拟环境都保留
- **服务管理**：`bosshost stop` 是彻底停用（开机也不自启），`bosshost start` 恢复；
  也可以直接用 `systemctl --user status codeboss`、`journalctl --user -u codeboss -f`
- **卸载**：`codeboss uninstall`（`--purge` 连数据一起清）或 `./uninstall-linux.sh --purge`

> 装完再敲 `claude` 也算数：别名会让它自动套一层镜像代理，终端里显示和原来一模一样，
> 手机端才拿得到全彩画面。

## Windows

**方式一：安装包（推荐）**——官网下载 `BossHost-Setup.exe`，**双击**，一路下一步即可。
不需要管理员权限；重复运行 = 原地升级；「应用和功能」里可以卸载（程序删掉、数据保留）。
装不上时先看 `%LOCALAPPDATA%\Codeboss\install.log`（安装器的弹窗里也会显示第一条报错）。

**方式二：压缩包**——解压后**双击 `安装.cmd`**（等价于在 PowerShell 里跑 `install.ps1`）：

```powershell
powershell -ExecutionPolicy Bypass -File .\install.ps1
```

安装包里自带 Python（不用机器上先装）→ 自动测速选最快的镜像装依赖 →
程序装到 `%LOCALAPPDATA%\Codeboss` → 注册计划任务「Codeboss」（登录自启、崩了 1 分钟后自动重启）→
放行防火墙 8790（需要管理员，失败不阻断）→ 登记中继并打印绑定二维码 → 把托盘加入启动项并启动。

### 托盘客户端（和 macOS 菜单栏 App 同一套功能）

装好后右下角通知区会出现 BossHost 图标（终端屏 + 安全帽），**右键就是菜单，双击打开主窗口**：

| 菜单项 | 作用 |
| --- | --- |
| 服务：运行中 / 已停止 | 实时状态（鼠标移上去也能在提示里看到） |
| 扫这个码接上… | 换一张新配对码，弹窗显示二维码（15 分钟有效，可刷新；没登记会先自动登记） |
| 查看会话列表… | 本机托管的 Claude 会话（名称 / 状态 / 目录），双击在浏览器里打开 |
| 启动服务 / 停止服务 | 启停计划任务（停止 = 开机也不再自启，恢复点「启动服务」） |
| 重新安装服务（覆盖，保留数据）… | 用当前程序文件覆盖安装目录，token/会话/配置都保留，装完自动重启服务 |
| 卸载服务… | 只卸载（保留数据）或彻底删除 |
| 套餐与续费… | 应用内看套餐/今日时长，选套餐扫码付款（支付宝/微信） |
| 检查更新… | 手动检查并安装新版本 |
| 打开主窗口 | 状态一览 + 未安装服务时的「三步接入」引导 |
| 退出 | 只关托盘（服务照常跑；下次登录会自动回来） |

托盘由「启动」文件夹里的 `BossHost` 快捷方式在登录时拉起，**关掉托盘不影响服务**；
服务挂了计划任务 1 分钟后会自己重新拉起。

- **前置**：[Git for Windows](https://git-scm.com/download/win)（Claude Code 自己就要它）+ Claude Code
- **不需要管理员**：计划任务是用户级的，装在用户目录
- **重复运行 = 原地升级**（token、历史、虚拟环境都保留；脚本会先停服务和托盘再覆盖文件）
- **命令行等价**（排障用）：`schtasks /Change /TN Codeboss /DISABLE` 停用、`/ENABLE` 恢复；
  `.venv\Scripts\python.exe tray.py --main` 手动开主窗口
- **看日志**：`%LOCALAPPDATA%\Codeboss\logs\server.log`（托盘自己的：`logs\tray.log`）
- **卸载**：托盘菜单「卸载服务…」，或 `powershell -ExecutionPolicy Bypass -File .\uninstall.ps1`
  （加 `-Purge` 连数据一起删）
- **能力边界**：Windows 没有可枚举/可注入的终端标签页，手机端只列 BossHost 自己托管的会话
  （新开一个会话即可）；本机终端里另外开的 `claude` 不在列表里
- **网络**：Claude Code 需要能连 api.anthropic.com；需要代理时在系统里设好 `HTTPS_PROXY`
  （BossHost 起子进程时继承环境变量）

## 使用

- 电脑终端里正常敲 `claude` 开始干活（装完后这个命令已透明接入镜像，用法不变；Mac / Windows / Linux 都一样）
- 手机浏览器/App 里能看到所有 claude 会话，点进去实时观看/插话/发送
- 三个视图：📱实时（推荐，自动适配手机排版）、🖥原样（逐字节还原终端）、💬聊天
- Mac 睡眠或重启后服务会自动拉起（launchd 托管）；Windows 登录后由计划任务拉起，服务崩了 1 分钟后自动重启；
  Linux 由 systemd 用户服务托管（`systemctl --user status codeboss`）

## 访问权限

- 手机用「扫这个码接上…」绑定，绑过的手机会直接连上，不用记密码
- 访问凭证由安装过程自动生成并保存，**不要把自己手机上的访问链接转发给别人**
- 换手机、或者想收回某台设备的访问：在开发机端重新生成一张配对码，用新手机重新绑定

## 权限弹窗说明（仅 macOS）

- **首次遥控终端**：macOS 会弹「“python”想要控制“Terminal”」→ 点**允许**。如果手滑点了拒绝：系统设置 → 隐私与安全性 → 自动化 → 把 python/Terminal 的开关打开
- 之后不会再弹

## 常见问题

- **手机打不开页面**：确认同一 Wi-Fi；确认防火墙放行了 8790 端口（Mac：系统设置 → 网络 → 防火墙；
  Windows：安装脚本会自动尝试放行，没放行就手动在「Windows 安全中心 → 防火墙和网络保护 → 允许应用通过防火墙」里勾选 python；
  Linux：云主机的安全组也要放行 8790）
- **提示无权访问 / 打不开**：在开发机端重新生成配对码，手机上重新扫码绑定一次
- **看不到会话**：终端里得有正在运行的 `claude`（新开终端敲一次 `claude`）；装完 alias 后要在**新开**的终端标签页里敲才生效
- **想换端口 / 换目录**：改 `server.py` 顶部的 PORT 后重新双击安装即可；挪目录则整个文件夹挪走后再双击一次安装

## 更新

- **自动**：发现新版本时页面顶部会出现「🚀 发现新版本」横幅，点「立即更新」→ 自动下载安装并重启，几秒完成
  - git 部署走 `git pull`；安装包装的（`~/.codeboss`）从自家中继自动下载安装（不依赖 GitHub 登录态），数据保留
- **手动**：Mac 点菜单栏的 BossHost 图标 →「检查更新…」；Windows 右键托盘图标 →「检查更新…」；
  Linux 装新包覆盖即可。也可以重新下载安装包再装一遍（Mac 把新版 `BossHost.app` 拖进「应用程序」覆盖），
  token 和记录都保留
- 检查频率：服务端 6 小时一次，手机页面开着时每 15 分钟一次

## 卸载

在 codeboss 文件夹里执行（Linux 用 `uninstall-linux.sh`，参数相同）：

```bash
./uninstall.sh          # 停服务、删自启，保留 token 和历史记录
./uninstall.sh --purge  # 彻底清除（连 claude 命令别名、虚拟环境、记录一起删）
```

## 安全边界

- 服务只监听局域网（0.0.0.0:8790），**没有公网暴露**；token 是唯一凭证
- `token.txt`、会话记录、日志都在本机，不外传
